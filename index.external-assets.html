macOS İçin Synaphe

Apple Silicon (M1–M4) ve Intel Mac'ler için hazır masaüstü başlatıcı. Tek tıkla yerel sunucuyu ayağa kaldırır ve arayüzü açar.

  • Paketi indirip zip dosyasını açın
  • Synaphe.app uygulamasına çift tıklayın
  • İsterseniz Ollama ile %100 internetsiz çalıştırın
macOS Paketini İndir (.zip)
macOS Terminal (Alternatif Kurulum) 
git clone https://github.com/karabul7tt/synaphe.git
cd synaphe
pip3 install -r requirements.txt
python3 -m uvicorn server:app --port 8000

Windows 10 / 11 İçin Synaphe

Windows bilgisayarında Python ile doğrudan yerel olarak çalışır; tüm hafızan bilgisayarındaki yerel veritabanında kalır.

  • Python 3.10+ yüklü olduğundan emin olun
  • Sağdaki komutları PowerShell'e yapıştırın
  • Tarayıcıda http://localhost:8000 adresini açın
GitHub'dan İndir
Windows PowerShell 
git clone https://github.com/karabul7tt/synaphe.git
cd synaphe
py -m pip install -r requirements.txt
py -m uvicorn server:app --host 127.0.0.1 --port 8000

Linux İçin Synaphe

Ubuntu, Debian, Fedora veya Arch üzerinde hafif FastAPI + NetworkX çekirdeğiyle milisaniyeler içinde çalışır.

  • Depoyu klonlayıp sanal ortam oluşturun
  • İsteğe bağlı ollama pull llama3.2 ile çevrimdışı mod açın
  • Yerel arayüze veya MCP sunucusuna bağlanın
Kaynak Kodu Gör
Linux Bash 
git clone https://github.com/karabul7tt/synaphe.git
cd synaphe && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --port 8000

iPhone & Android (Mobil Erişim)

Sokaktayken, yoldayken veya not almak istediğinde telefonundan sesli ya da yazılı mesaj at — Telegram köprüsü aracılığıyla doğrudan kendi bilgisayarındaki Synaphe hafızana ulaş.

  • Telegram'da @BotFather üzerinden kendi bot token'ını oluştur
  • Bot yalnızca ilk /start atan sahibine (sana) kilitlenir
  • Sesli mesaj gönder, anında hafızana işlensin veya sorgulansın
Telegram Mobil Köprüsü 
export TELEGRAM_BOT_TOKEN="BOT_TOKENINIZ"
python3 telegram_bot.py

# iOS veya Android'de botunuza /start yazın.
# Artık tüm sesli ve yazılı notlarınız Synaphe'e aktarılır.

Claude Desktop, Cursor & Zed

Kullandığın yapay zekâ araçlarına Synaphe'in kalıcı hafızasını doğrudan ekle. 4 hazır araç (remember, recall, somatic_marker, proof) otomatik aktif olur.

  • Sağdaki JSON bloğunu MCP ayar dosyanıza ekleyin
  • Uygulamayı yeniden başlatın
  • Artık Claude veya Cursor geçmişini hiç unutmaz
claude_desktop_config.json 
{
  "mcpServers": {
    "synaphe": {
      "command": "python3",
      "args": ["/path/to/Synaphe/mcp_server.py"],
      "env": { "SYNAPHE_API_URL": "http://127.0.0.1:8000" }
    }
  }
}
